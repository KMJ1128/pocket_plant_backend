# PocketPlant 자동 급수 배선 및 보정

## 준비물

- Geekble Mini ESP32-C3
- SZH-RLBG-007 5V Low-trigger 1채널 릴레이
- SZH-GNP139 DC 펌프
- 펌프용 6V 전원(최소 1A 권장)
- 1N4007 등의 플라이백 다이오드
- 호스, 물통, 점퍼선

펌프는 Geekble 보드의 3.3V 또는 5V 핀에서 전원을 공급하지 않는다.
USB 전원과 분리된 펌프 전원을 사용한다.

## 제어부 배선

| Geekble Mini ESP32-C3 | 릴레이 모듈 |
|---|---|
| D6 (GPIO6) | IN |
| 안정된 외부 5V | VCC |
| GND | GND |

이 펌웨어는 Low-trigger 기준으로 `LOW=ON`, `HIGH=OFF`를 사용한다.
릴레이 입력부의 GND와 Geekble GND는 반드시 공통으로 연결한다.
VUSB/5V 핀을 쓸 때는 보드 핀 표기와 USB 전원 용량을 먼저 확인한다.
모터를 연결하기 전 릴레이 LED와 접점 소리만으로 ON/OFF를 먼저 시험한다.
3.3V HIGH에서 릴레이가 확실히 꺼지지 않으면 직접 연결을 중단하고
3.3V 호환 릴레이 또는 트랜지스터 레벨 변환 회로를 사용한다.

## 펌프 전원부 배선

| 연결 시작 | 연결 끝 |
|---|---|
| 펌프용 전원 + | 릴레이 COM |
| 릴레이 NO | 펌프 + |
| 펌프 - | 펌프용 전원 - |

NC가 아니라 NO 단자를 써야 평상시에 펌프가 꺼져 있다.
다이오드는 펌프 단자에 역방향으로 병렬 연결한다.
띠가 있는 캐소드 쪽은 펌프 +, 애노드는 펌프 -에 연결한다.

## 업로드

1. Arduino IDE에서 보드를 `Geekble ESP32C3`로 선택한다.
2. `sketch_may8a.ino`를 연다.
3. `SERVER_BASE_URL`을 실제 백엔드 주소로 확인한다.
4. 업로드 후 시리얼 모니터를 115200 baud로 연다.
5. 앱에서 기존 방식대로 Wi-Fi를 전달한다.

## 필수 보정

1. 토양 센서를 공기 중에 두고 raw 값을 확인해 `SOIL_DRY_ADC`에 넣는다.
2. 젖은 흙에 넣고 안정된 raw 값을 `SOIL_WET_ADC`에 넣는다.
3. 호스를 실제 높이와 길이로 설치한다.
4. 펌프를 정확히 10초 돌려 받은 물의 mL를 잰다.
5. `측정 mL / 10` 값을 앱의 `펌프 보정값(초당 mL)`에 저장한다.
6. 수동 급수를 여러 번 확인한 뒤에만 자동 급수를 켠다.

기본 보정값 30mL/초는 임시값이다. 제품 표기의 무부하 유량을 그대로
사용하면 호스 높이와 실제 부하 때문에 급수량 오차가 크게 날 수 있다.
